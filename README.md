# 水仙十字題解

一個以《原神》楓丹「水仙十字」相關故事為主題的 SwiftUI 導覽 App。透過角色介紹、劇情章節、意象圖鑑與本地手書影片，整理水仙十字院、結社與後日談的脈絡。

## 功能

- **首頁**：故事摘要、章節預覽與關鍵角色入口。
- **角色介紹**：瀏覽人物身分、所屬時代及詳細背景。
- **劇情介紹**：依章節閱讀水仙十字故事的時間線。
- **手書影片**：播放隨 App 打包的本地 `ShuiXianVideo.mp4`。
- **意象圖鑑**：以圖片與短文整理故事中的重要場景與物件。

## 技術

- SwiftUI
- AVKit（本地影片播放）
- WebKit（保留的跨平台 WebView 元件）
- UIKit（iOS 橫直向切換）

## 專案結構

| 路徑 | 說明 |
|---|---|
| `hw5261111/ContentView.swift` | 資料模型、SwiftUI 頁面與影片播放邏輯 |
| `hw5261111/MyApp.swift` | App 進入點與 iOS 方向控制 |
| `hw5261111/Assets.xcassets` | 角色、章節與圖鑑使用的影像資源 |
| `hw5261111/ShuiXianVideo.mp4` | 本地手書影片資源 |

## 執行方式

1. 使用 Xcode 開啟專案。
2. 選擇 `hw5261111` scheme 與可用的 iOS 模擬器或實機。
3. 按下 Run（⌘R）建置並啟動 App。

## 使用說明

App 以分頁呈現五個區域：**首頁、角色、劇情、手書、圖鑑**。進入「手書」分頁時，畫面會切換為橫向，以便播放影片；離開後會恢復一般直向介面。
